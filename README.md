# FTPClient Pro v1.0
Modern arayüzlü, çift motorlu (FTP & SFTP) dosya transfer istemcisi.

## Özellikler
* 🚀 **Çift Motor:** Klasik FTP ve Güvenli SFTP (SSH.NET) desteği.
* 🔐 **Güvenlik:** DPAPI ile şifrelenmiş kayıtlı siteler.
* 🌑 **Dark Mode:** Göz yormayan modern WPF arayüzü.
* 📂 **Drag & Drop:** Masaüstünden sürükle-bırak ile dosya yükleme.
* 💾 **Backup:** Siteleri XML olarak içe/dışa aktarma.
